# دليل إعدادات برايم تكت

افتح **Prime Ticket Settings** من مساحة عمل برايم تكت. تتوفر النسخة العربية من الدليل داخل التطبيق على `/prime-ticket-settings-guide-ar`، والنسخة الإنجليزية على `/prime-ticket-settings-guide`.

## قبل البدء

إعدادات برايم تكت مستند واحد لإعدادات التطبيق على مستوى الموقع. تحتاج إلى دور **System Manager** لتعديلها، ثم احفظ النموذج بعد إجراء التغييرات.

> **ملاحظة حول التنفيذ الحالي:** معظم الحقول موجودة وتحفظ قيمها، لكن كود معالجة التذاكر لا يستخدمها حالياً. التعيين التلقائي، ومؤقتات SLA، وسير العمل المخصص، والإغلاق والتصعيد التلقائي، ومفاتيح الإشعارات، ورمز API، والـ Webhook، وحقول JSON لا تغيّر سلوك التطبيق حالياً. الشعار هو الاستثناء: يظهر في نموذج إرسال التذكرة وصفحة الدليل عند ضبطه. رسائل البريد تعتمد حالياً على سجلات Notification التي ينشئها التطبيق عند التثبيت أو الترحيل.

## الإعدادات العامة

| الإعداد | الغرض | السلوك الحالي |
| --- | --- | --- |
| Application Name | اسم لعلامة التطبيق التجارية. | يُحفظ لكنه لا يغيّر الواجهة حالياً. |
| Application Logo | صورة لعلامة التطبيق. | تظهر في نموذج إرسال التذكرة وصفحة الدليل عند ضبطها. |
| Enable Auto-Assignment of Tickets | مفتاح مقصود للتعيين التلقائي. | لا يوجد كود تعيين تلقائي يستخدم هذا المفتاح حالياً. |
| Auto-Assignment Method | الطرق المعروضة: Round Robin وLeast Busy وSame Category وRandom. | يظهر عند تفعيل التعيين التلقائي، لكن لا يجري تطبيق أي طريقة حالياً. |
| Enable Email Notifications | مفتاح مقصود للتحكم بإشعارات البريد. | لا يفعّل أو يعطّل سجلات Notification التي ينشئها التطبيق. أدرها من **Notification** في Frappe. |
| Enable SLA Tracking | مفتاح مقصود لمراقبة SLA. | لا يبدأ مؤقتات SLA ولا يحسب مهل التذاكر. |
| Default SLA Response Time (Hours) | مهلة الاستجابة الافتراضية المقصودة؛ قيمتها الافتراضية 24 ساعة. | تُحفظ فقط ولا تُفرض حالياً. |

## إدارة المشغّلين

| الإعداد | الغرض | السلوك الحالي |
| --- | --- | --- |
| Support Operators | جدول فرعي لاختيار سجلات Prime Ticket Operator. | يحفظ الاختيارات لكنه لا يعيّن التذاكر ولا يمنح الأدوار. أضف دور **Ticket Operator** للمستخدم بشكل منفصل في **User** ضمن Frappe. |

يحتوي **Prime Ticket Operator** على مستخدم Frappe وبيانات الاتصال والفئات والسعة والمهارة وساعات العمل والمنطقة الزمنية والتوفر ومفاتيح الصلاحيات. لا يستخدم متحكم التذاكر هذه البيانات حالياً لتوزيع العمل أو فرض الصلاحيات.

## إعداد سير العمل

| الإعداد | الغرض | السلوك الحالي |
| --- | --- | --- |
| Enable Custom Workflow | مفتاح مقصود للحالات المخصصة. | لا يغيّر خيارات حالة Support Ticket أو يتحقق من انتقالات الحالة. |
| Custom Workflow Statuses | صفوف فرعية للاسم والوصف واللون والترتيب. | تحفظ فقط. الحالات الفعلية ثابتة: Open وWorking in Progress وPending وWaiting for Reply وResolved وReopened وClosed. |
| Auto-Close Resolved Tickets (Days) | مدة مقصودة قبل إغلاق التذكرة المحلولة؛ الافتراضي 7 أيام. | لا توجد مهمة مجدولة تستخدم القيمة. |
| Auto-Escalate Unresponded Tickets (Days) | مدة مقصودة قبل تصعيد التذكرة؛ الافتراضي 3 أيام. | لا توجد مهمة مجدولة تستخدم القيمة. |

## فئات التذاكر

يختار جدول **Categories** سجلات Prime Ticket Category. يحتوي هذا النوع على الاسم والوصف واللون وفئة الأيقونة وحالة التفعيل. نموذج العميل يستخدم حالياً خيارات ثابتة: Question وBug Report وFeature Request وHow-To وOther. لا تغيّر قائمة الإعدادات خيارات النموذج.

## سياسات SLA

يحفظ كل صف سياسة اسم الأولوية ومدة الاستجابة بالساعات ومدة الحل بالساعات ولوناً اختيارياً. هذه السياسات جداول فرعية تُحرر داخل Prime Ticket Settings؛ لا تفتحها كقائمة مستقلة. لا يقارن التطبيق عمر التذكرة بهذه المهل ولا يرسل تنبيهات تجاوز SLA حالياً.

## إعدادات الإشعارات

| الإعداد | الغرض | السلوك الحالي |
| --- | --- | --- |
| Notify Operators on New Ticket | مفتاح مقصود لتنبيه المشغّلين عند إنشاء تذكرة. | إشعارات التطبيق ترسل إلى دور Ticket Operator بغض النظر عن هذا المفتاح. |
| Notify Customer on Status Change | مفتاح مقصود لإشعارات الحالة للعميل. | تُرسل إشعارات Resolved وWaiting for Reply بغض النظر عن هذا المفتاح. |
| Notify Operator on Assignment | إشعار مقصود عند إسناد تذكرة. | لا يوجد حالياً سلوك إشعار عند الإسناد. |
| Custom Email Template | اختيار قالب بريد. | يُحفظ فقط؛ إشعارات التطبيق لا تستخدم هذا الحقل حالياً. |

يلزم ضبط حساب بريد صادر في Frappe لإرسال الرسائل. راجع قواعد التطبيق الحالية في DocType **Notification**.

## قواعد التصعيد

| الإعداد | الغرض | السلوك الحالي |
| --- | --- | --- |
| Enable Escalation | مفتاح مقصود للتصعيد. | لا توجد عملية تصعيد مجدولة تقرأه حالياً. |
| Escalation Levels | صفوف فرعية للمستوى والوصف ومدة الانتظار بالأيام والدور الذي سيُخطر. | تُحفظ فقط ولا تستخدمها عملية مجدولة حالياً. |

## التكاملات

| الإعداد | الغرض | السلوك الحالي |
| --- | --- | --- |
| Enable External API Access | مفتاح مقصود للوصول عبر التكاملات. | لا ينشئ نقطة API ولا يغيّر مصادقة Frappe. |
| API Token | حقل من نوع Password لرمز مقصود. | لا توجد نقطة في التطبيق تقرأ هذا الحقل أو تتحقق منه. استخدم مصادقة Frappe وصلاحيات مستخدم Frappe للتكاملات. لا تضع سراً إنتاجياً هنا على أساس أنه سيفعّل API. |
| Webhook URL | عنوان مقصود لاستقبال الأحداث. | لا يرسل التطبيق أحداثاً إلى هذا العنوان حالياً. |

## الإعدادات المتقدمة

| الإعداد | الغرض | السلوك الحالي |
| --- | --- | --- |
| Custom Fields (JSON) | إعداد مقصود لحقول إضافية. | يُحفظ كنص ولا يجري تحليله أو تطبيقه. |
| Custom Business Rules (JSON) | إعداد مقصود لقواعد عمل مخصصة. | يُحفظ كنص ولا يجري تحليله أو تطبيقه. |
| Allow Customers to Reassign Tickets | مفتاح مقصود للسماح للعملاء بإعادة الإسناد. | لا يغيّر الصلاحيات ولا يضيف إجراء إعادة إسناد حالياً. |

## ما يعمل حالياً

- أدوار Frappe وصلاحيات DocType تتحكم في الوصول إلى التذاكر.
- يسجل Support Ticket المستخدم الحالي كصاحب الطلب ويجلب بريده عند توفره.
- ينشئ التطبيق إشعارات Frappe عند إنشاء التذكرة وعند تحويلها إلى Resolved أو Waiting for Reply أو Reopened.
- حالات Support Ticket ثابتة في DocType. يسجل التطبيق `resolved_at` عند اختيار Resolved ويمسحه عند العودة إلى حالة نشطة.

لتغيير الإشعارات الفعلية، استخدم **Notification** في Frappe. ولتغيير فئات نموذج التذكرة أو خيارات الحالة، حدّث تعريف DocType Support Ticket ثم نفّذ ترحيل الموقع.
